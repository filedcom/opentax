# TY2025 registered attachment inventory A — 26 descriptors

This is a static audit of exactly 26 registered descriptors in
`forms/f1040/2025/mef/forms/index.ts`: Form 965-A and its two statements, 982,
1099-R, Form 1116 and its Schedule B/three statements, 2439, 2441, 2555, 3800, Form
4136 and four statements, 4137, 4255, 4562, 4684, 4797, 4835, and 4952. Each row
distinguishes a source/calculation route from mere serializer registration.
`PDF` means a registered fill descriptor; `binary` means a separately attached
source PDF, not a filled form. A missing PDF descriptor is an open product
decision, not evidence that one is unnecessary.

Evidence state for **every row**: named cases below are **written, not run in
the current worktree**. The deferred full-batch tests, typecheck, local
TY2025v5.4 XSD validation, filled-PDF appearance review, IRS business rules,
end-to-end filed-return check, and ATS acceptance have **not** been performed. A
named `.xsd.test.ts` is a written case, not a current pass. `No named case`
means this audit did not find one, not that a case failed. No row below has
accepted ATS evidence.
