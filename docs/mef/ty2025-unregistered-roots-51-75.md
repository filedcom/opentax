`Applicable; unsupported` means an individual Form 1040 situation can need the
document but the native filing path is absent or rejects. `Needs decision`
keeps attachment and workflow classification open. `Source-only candidate`
requires a TY2025 MeF rule check before omitting a payer/entity form. No row is
excluded, and a named input or written test is not filing readiness.
