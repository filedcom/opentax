prior six 12-root tranches. The checked-in
[`ty2025-xsd-document-root-census.md`](ty2025-xsd-document-root-census.md) lists
all twelve. A registered descriptor or a written test is not a passed return. No
product-path exclusion is approved here. Status below means code and test files
inspected on 2026-09-28; the coordinated test, TY2025 XSD, filled-PDF,
business-rule, and ATS batches have not run for this tranche.
