## Decision and verification queue

1. **No form-level exclusion is recommended for these six.** All are applicable
   to some Form 1040-family returns; nonfiling conditions (for example, Form
   7217 money-only distributions) are tax-rule branches, not product-scope
   exclusions. Unsupported active branches should reject or be proven gated;
   they must not silently disappear.
2. Form 6198 trigger trace below finds no **proven** active positive source that
   silently omits a required Form 6198. It does not establish completeness: K-1
   facts do not distinguish an all-at-risk loss from one requiring the form, and
   the extra borrowed-amount and recapture triggers have no complete public
   source model.
3. Form 6252 production call-site trace: `mef/builder.ts` calls every descriptor
   from `buildReturnXml` with `{ pending }` in both initial and linked passes.
   `pdf/builder.ts` passes normalized `pending` into `form6252Pdf.instances`,
   which passes it to `validateDestinations`; both exports therefore reject a
   positive line 26 when the matching Schedule D/Form 4797 source amount is
   absent or unequal. The context-optional **direct descriptor** call can emit
   XML without this check (existing unit tests use it), but no production export
   path found invokes it that way. This is not a demonstrated export leak, so no
   guard was added. Continue to prove that the matched Schedule D/Form 4797
   amount itself is finalized and source-backed; the equality guard alone is not
   that proof.
4. For each accepted branch, run the deferred source-to-return assertions,
   native v5.4 XSD, conditional IRS business rules, actual filled-PDF
   field/appearance inspection and ATS acceptance. Focused cases already written
   in the repository remain **written but unrun** for this audit.

## Form 6198 public-source trigger trace

This trace compares the
[IRS “Who Must File” rule](https://www.irs.gov/pub/irs-prior/i6198--2025.pdf)
with typed source and both exporters. It is static evidence only; no cases or
exporters were run. In particular, “some investment not at risk” plus an
activity loss is a concrete attachment trigger; a loss without that fact is not.

| Public source       | Active trigger and output evidence                                                                                                                                                                                                                                                                         | Residual uncertainty                                                                                                                                                                                                                                                                                         |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Schedule C          | `schedule_c/model.ts` requires simplified facts for a preliminary loss marked line 32b and rejects facts inconsistent with 32b/loss. `mef/forms/f6198.ts` and `pdf/forms/f6198.ts` recalculate that activity and project one IRS6198/PDF instance.                                                         | Source does not fully model prior-year suspended loss, detailed basis, recapture, or the IRS additional borrowed-amount trigger.                                                                                                                                                                             |
| Schedule F          | `schedule_f/index.ts` makes the equivalent line 36b/loss/facts check. Both Form 6198 exporters recalculate and project one instance per affected farm.                                                                                                                                                     | Same unsupported detailed, carryover, recapture and additional-borrowing conditions.                                                                                                                                                                                                                         |
| Form 4835           | `f4835/index.ts` requires line 34 at-risk answer for a preliminary loss and simplified facts when 34b is true. `mef/forms/f4835_at_risk.ts` emits a separate IRS6198 per affected activity; `mef/forms/f4835.ts` checks the linked IRS6198 document count. `pdf/forms/f6198.ts` includes these activities. | Detailed computations and positive-income recapture are not modeled. The Form 4835 attachment is **not** missing merely because `mef/forms/f6198.ts` itself only reads C/F.                                                                                                                                  |
| Schedule E property | `schedule_e/index.ts` rejects any `some_investment_not_at_risk=true` or positive `prior_unallowed_at_risk`; `mef/forms/schedule_e.ts` also rejects these carryover/at-risk paths.                                                                                                                          | A taxpayer may have Form 6198 filing facts not represented in this property source; no supported positive at-risk-property route was found.                                                                                                                                                                  |
| Partnership K-1     | `k1_partnership/index.ts` can route negative boxes 1–3 to Schedule 1 without Form 6198; it also stores pre-2018 at-risk suspension amounts as informational fields, not released current-year losses. No current-year “some not at risk” activity flag or amount-at-risk computation is present.           | A negative K-1 amount can be wholly at risk, so the typed input does **not prove** a required Form 6198. This is a source-model/eligibility gap, not a demonstrated missing-attachment leak. A reviewed per-activity loss/borrowing/basis history is needed before accepting that branch as filing-complete. |
| S-corporation K-1   | `k1_s_corp/index.ts` rejects prior at-risk suspended amounts and requires a narrow reviewed stock-basis ledger for a negative ordinary box 1. It does not create Form 6198 or establish all-at-risk status.                                                                                                | Stock basis and at-risk limits differ. A sourced at-risk determination is still needed for the otherwise active stock-basis loss route; a negative K-1 alone does not establish that Form 6198 is required.                                                                                                  |

No code guard was added because the inspected active typed facts do not prove an
omitted required attachment. The next targeted work is source design for K-1
at-risk status and the extra IRS borrowed-amount/recapture triggers, followed by
a guard or native calculation for any affirmative trigger.
