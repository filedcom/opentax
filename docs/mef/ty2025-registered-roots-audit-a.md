Static current-worktree review, 2026-09-28. These twelve `ReturnData1040.xsd`
roots have source literals and registered native descriptors. Registration is
not whole-form coverage, a test pass, or IRS acceptance. The source boundaries
below follow the public/input node, native descriptor, and registered PDF
descriptor, with the IRS instructions supplying the filing trigger. No path is
excluded by this review. The full batch, TY2025 XSD, filled-PDF inspection,
business-rule review, and ATS acceptance have not run.
