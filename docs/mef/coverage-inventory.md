Scope: the user selected the TY2025 Form 1040 family, excluding separate
1040-NR, 1040-SS, and 4868 returns. This inventory is an audit index, not a
support claim. `forms/f1040/2025/mef/forms/index.ts` is the authoritative list
of registered serializers; the local TY2025v5.4 `ReturnData1040.xsd` is the XML
sequence/type authority. The XSD permits many more documents than this product
currently emits, so registration and XSD allowance must not be confused with
tax-situation coverage.
