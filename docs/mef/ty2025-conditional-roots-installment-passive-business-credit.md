# TY2025 conditional-root inventory: installments, passive activity, and business credits

Static 2026-09-28 audit of twelve `ReturnData1040.xsd` roots, separate from
the housing/child/PFIC and other coverage tranches. The checked-in source
nodes, `forms/f1040/2025/mef/forms/index.ts`,
`forms/f1040/2025/pdf/forms/index.ts`, and form-specific gap notes establish
only current implementation shape. No unsupported path is excluded by this
inventory. Written cases are not current passes: the agreed full test batch,
TY2025 XSD validation, filled-PDF inspection, business-rule check, and ATS
acceptance have not run.

These twelve rows describe narrower positive routes and explicit rejections; none
has recorded ATS acceptance. Current native/PDF registration is not a substitute
for the deferred full-batch, schema, rendered-PDF, and IRS acceptance gates.

Form 6252 context qualification: a separate production call-site trace in
`coverage-inventory-sparse-decisions.md` found that both MeF and PDF builders
pass pending return context to the destination guard. The optional context is
a direct-descriptor API property, not a demonstrated production export leak.
The outstanding issue is source-backed sale and obligation history plus proof
that the matched Schedule D/Form 4797 amount is finalized, not absence of
pending context in the traced exporters.
