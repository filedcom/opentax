# TY2025 remarried separate parent sources and required child tax

## Existing gap and official scope

The prior source checkpoint covers single custodial/cohabiting parents and
remarried custodial MFJ parents. This continues the existing education/family
source task when the custodian and new spouse actually file separate returns.

[2025 Form 8615 instructions, pages 1–2](https://www.irs.gov/pub/irs-prior/i8615--2025.pdf)
select the greater taxable-income return of a remarried custodian and stepparent
who file separately and live together. The noncustodial parent is excluded.
Lines A/B identify that actual selected person, including a stepparent; line C
uses MFS. Actual other eligible children's line5 amounts enter the allocation;
line10 uses the selected parent's actual before-credit income tax.

[2025 Form 1040 instructions](https://www.irs.gov/pub/irs-prior/i1040gi--2025.pdf)
provide the MFS $15,750 standard deduction, zero standard deduction when the
spouse itemizes, and separate ownership of income/deductions subject to
community-property rules. [2025 Form 8863 instructions, page 3](https://www.irs.gov/pub/irs-prior/i8863--2025.pdf)
bar education credits on MFS returns. Required child tax still applies when
neither parent can claim AOC or LLC.
