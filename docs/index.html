FAQ

Questions about the engine

If something here is wrong or missing, open an issue on GitHub.

What is OpenTax?

OpenTax is a free, open source federal tax calculation engine. It computes Form 1040 and its schedules from source-document inputs, checks the result against the IRS Modernized e-File business rule set, and exports MeF XML or a filled IRS PDF. It ships as a single binary for macOS, Linux and Windows, and it is built to be driven by AI agents as much as by people.

Is OpenTax really free?

Yes. The engine is licensed under AGPL v3 at no cost. A separate commercial licence is available for organisations whose policies prohibit AGPL. Both founding members of the Open Tax Technology Alliance have committed that neither OpenTax nor the Open Tax Document standard will be monetised.

Can I file my tax return with OpenTax?

No. OpenTax calculates returns, checks implemented MeF business rules, and exports MeF XML or a filled IRS PDF. CLI export does not run XSD validation. Optional developer XSD tests require a separate IRS schema bundle and may be skipped when it is absent. The CLI does not transmit returns, retrieve acknowledgements, or establish IRS acceptance. Any transmission path, required authorization, testing, signatures and acceptance/rejection handling must be established separately.

Which forms and tax years does OpenTax support?

Form 1040 for tax year 2025, across 186 registered nodes and 131 input types. That covers W-2s, the 1099 series, K-1s, and Schedules A, C and E, along with the major credits and capital transactions. Additional forms and state returns are planned but not implemented. Run opentax node list to see everything currently registered.

Does my tax data leave my computer?

The CLI stores return files locally. This is not a guarantee that your whole workflow is local-only: documents uploaded into a hosted assistant or cloud chat are handled by that assistant provider. Review your tools, storage and data-handling arrangements before supplying taxpayer documents.

How is the engine tested for accuracy?

The repository includes 133 benchmark scenarios drawn from official IRS material, including VITA Publication 4491 training exercises, Publication 17 worked examples, and MeF test packages. Each case pairs inputs with expected output so regressions surface immediately. Returns are also validated against the IRS MeF business rules, with hard failures separated from softer warnings. The benchmark suite and the tests are public, so you can run them yourself with deno task bench.

How do I use OpenTax with Claude or ChatGPT?

Three ways. Add the MCP connector, which works across all sessions in either assistant. Paste the skill URL into a Claude chat, which fetches and installs everything for you with no prior setup. Or, in Claude Code, install it as a plugin with /plugin marketplace add filedcom/opentax followed by /plugin install opentax@opentax.

What is Open Tax Document?

Open Tax Document is a free YAML standard for creating and reading Schedule K-1 data, published as a public draft at opentaxdocument/otd-spec. It is the second Alliance initiative, separate from the engine. Anyone can read and implement it, with no licence to acquire and no vendor to go through.

Who builds and maintains OpenTax?

Filed and Crimson Tree Software founded the Open Tax Technology Alliance and co-develop both initiatives. The engine's day-to-day maintenance runs largely through AI agents that read IRS instructions, write node implementations, generate test cases from official IRS exercises, and fix regressions, with IRS publications as the source of truth and a human reviewing changes before merge.

Can I contribute or build on it?

Yes, and the Alliance is open to any firm, developer or individual. You can extend the K-1 standard or build additional IRS forms into the engine. One restriction: the right to apply for IRS MeF Software Developer or Transmitter authorisation using this codebase is reserved to Filed and its authorised partners, so contact Filed in writing first if that is your plan. Tax professionals who don't write code can start with our guide to building on OpenTax.

How do I install and update the CLI?

One command installs it: curl -fsSL https://raw.githubusercontent.com/filedcom/opentax/main/install.sh | sh. It detects your OS and architecture and puts the right binary on your PATH. Signed release binaries for Apple Silicon, Intel Mac, Windows x64, Linux x64 and Linux ARM are also on the GitHub releases page. The CLI tells you when a new version exists, and opentax update replaces the binary in place.

How does OpenTax differ from Filed's commercial products?

OpenTax is the calculation layer on its own: deterministic arithmetic, no interface, no document reading. Filed is the commercial product that reads source documents the way a preparer does and then prepares and reviews returns inside a firm's existing tax software. OpenTax gives an AI assistant a calculator it can trust; Filed does the professional work around it.

The Alliance

Open to any firm, developer or individual

Federal tax calculation has been closed software since the 1990s, sold on annual licences by a small number of vendors. The arithmetic is no longer the hard part of tax work, and keeping it proprietary holds back everyone building on top of it.

Founding members

Filed

AI that works inside a tax firm's existing software. Reads the same source documents a preparer reads, then prepares and reviews returns. Supports 1040, 1041, 1065, 1120, 1120-S and 990, and works with CCH Axcess, UltraTax, Lacerte, Drake and ProConnect.

Crimson Tree Software

Partnership tax automation for large public accounting firms, covering federal, state and international compliance for complex allocations and tiered structures. Joins as co-founding member and co-develops both initiatives.

Contributors can extend the K-1 standard or build additional IRS forms into the engine. Both founders have committed that neither initiative will be monetised.

Commercial use
